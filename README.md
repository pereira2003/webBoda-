# webBoda-

Sitio estático de invitación de boda (tema jardín). Publicado en la rama `main` listo para GitHub Pages.

Instrucciones rápidas:

1. Pages URL (esperada): https://pereira2003.github.io/webBoda-/  
   - Puede tardar unos minutos en activarse tras el primer push.

2. Formulario RSVP: está configurado para Formspree. Reemplaza `YOUR_FORMSPREE_ID` en `index.html` por tu ID de Formspree.
   - Crear proyecto en https://formspree.io/ y obtener el endpoint.

3. Imágenes: actualmente se usan imágenes de ejemplo (picsum). Para usar tus fotos:
   - Sube imágenes a `assets/images/` en el repo y reemplaza las URLs en `index.html`.

4. Si quieres recibir RSVPs en CSV o usar PHP, necesitarás hosting con PHP; GitHub Pages no ejecuta PHP.

5. Para editar el contenido (nombres, fecha, lugar): modifica `index.html`.

Si quieres que:
- Reemplace las imágenes por tus fotos, súbelas aquí o pásame URLs.
- Configure Formspree por ti (necesito el ID) — puedo actualizar el archivo.
